## 四、既定口径清单（K 编号 · "动了会打挂测试"）

> 下一棒开工前先读这一节。任何一条变更都必须同步：代码 → 测试 → README → 本表 → 决策记录（五处）。

| K | 口径 | 落点 | 违反的后果 |
|---|---|---|---|
| **K1** | **退出码语义**：`0` 无冲突 / `1` 有冲突 / `2` 用法错误 / `3` 依赖或环境缺失 / `4` 阶段未就绪（骨架期专用）。**退役四步**：删常量 → 改 CLI 与测试（含 `not hasattr` 防复活）→ 改 README 退出码表 → 改决策记录 | `exit_codes.py` / `cli.py` / `tests/test_cli_contract.py` / README | 幽灵语义复活；测试替不存在的分支说谎 |
| **K2** | **冻结序列化契约**：`json.dumps(sort_keys=True, ensure_ascii=False, indent=2)` + LF + 结尾换行 + 原子写（临时文件→rename）。所有写盘只经 `serialize.write_atomic` | `serialize.py` | 同输入双跑不再逐字节一致；报告 diff 噪音 |
| **K3** | **数值口径唯一权威 = `config/radar.toml`**；代码**零内联默认值**，缺键/未知键显式报错（exit 3），**不回落默认值** | `config.py` / `config/radar.toml` | 出现第二份真相；阈值漂移无告警 |
| **K4** | **只读纪律**：不执行 merge/rebase、不写 git 索引、不改工作区、不建分支；`merge-tree` 只允许 `--write-tree`（写对象库临时 tree，报告中如实披露**不得**声称"零任何写入"） | `gitio.py` / `detect.py` | 破坏用户工作区；定位从"预警"退化为"裁决" |
| **K5** | **零内联阈值字面量门禁**：策略数值不得作为字面量出现在 `src/`（白名单：`exit_codes.py` 的 `0–4`、`serialize.py` 的 `indent`）；同时 **import 面门禁**：下层禁止 import 上层 | `tests/test_config_literals.py` | "数值一处定义"退化为口号；分层被击穿 |
| **K6** | **底线解释器能力缺口处置**：缺能力时自写受限子集 + 超集形态**显式标记**（`toml_unsupported`），**不静默跳过、不引入运行时依赖** | `config.py` | 数据凭空消失；"本机 3.12 能读、3.8 读不出"分叉 |
| **K7** | **会话格式版本指纹**：显式集合；未知版本报 `unsupported_format` + 列出缺失键 + 点名文件；未闭环项（R1–R3）一律落 `unknown`，**不进检测路径** | `versions.py` / `discover.py` | 静默空表被读成"没有冲突" |

| **K9** | **真值只存"输入与期望"**；出现 `observed_*` 字段即红；期望值必须可由输入独立复算；生成器与真值**同步产出**，禁事后手补 | `bench/gen.py` / `bench/**/truth.json` | 基准退化成"比对两份预先算好的答案"，引擎全坏也全绿 |

## 五、数值口径的唯一位置与读取方式

- **唯一权威**：`config/radar.toml`。README / 技术报告 / 报告产物 / 基准输出**一律引用**，不得复制第二份数值表。
- **读取方式**：`config.load(path)` → 冻结的只读映射；缺文件/缺键/未知键/TOML 超集形态 → `ConfigError`（exit 3），**绝不回落默认值**。
- **可核验性**：`radar config` 打印**生效配置**（含来源路径），使"报告里的阈值从哪来"随时可查。
- **禁第二份的守门**：K5 零内联阈值字面量门禁 + K3 零内联默认值。
